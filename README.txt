# Darvig Molas - versão pronta para cPanel

Arquivos principais:
- `index.html`: landing page principal
- `produtos.html`: página de produtos
- `assets/css/landing.css` e `assets/js/landing.js`: arquivos separados da landing
- `assets/css/produtos.css` e `assets/js/produtos.js`: arquivos separados da página de produtos
- `painel/index.html`: painel industrial
- `painel/css/main.css`, `painel/js/main.js`, `painel/img/logo.png`: arquivos do painel

Como subir:
1. Extraia este ZIP.
2. Envie o conteúdo da pasta para `public_html` no cPanel.
3. Acesse o domínio para abrir a landing.
4. Acesse `/produtos.html` para produtos.
5. Acesse `/painel/` para o painel industrial.

Observação:
A estrutura visual e a lógica foram preservadas; apenas CSS e JS embutidos foram separados em arquivos externos.
